Invoice Extractor API

Invoice Extractor API v1.1.0

FastAPI service using PyMuPDF + Tesseract OCR + rule-based parsing (not a generative AI model).

Docs · Health · Ready · RapidAPI

  • No intentional long-term storage of invoice files.
  • Default raw-text response disabled for privacy.
  • Supported OCR languages: eng/ara/fra/ita/hin.

Limitations: OCR quality depends on file quality; parser is rule-based and may miss unusual layouts.
